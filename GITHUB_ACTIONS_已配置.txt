🚀 快速开始：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 配置 GitHub Secrets（必需）：
   进入仓库 Settings → Secrets and variables → Actions
   添加以下密钥：
   • CLIENT_ID
   • CURSEFORGE_API_KEY
   • TELEMETRY_KEY
   • NAID_CLIENT_ID
   • NAID_CLIENT_SECRET
   • LINK_SERVER_ROOTS
   • LOBBY_DEFAULT_SECRET

2. 推送代码：
   git add .
   git commit -m "添加 GitHub Actions 自动构建配置"
   git push

3. 查看构建：
   访问 GitHub Actions 页面查看自动构建状态

4. 下载产物：
   在 Actions 页面的工作流运行中下载构建产物
